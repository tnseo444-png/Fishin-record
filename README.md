# 낚시 기록 관리자

간단한 낚시 기록 관리 웹앱입니다. HTML, Vanilla JS, Tailwind CSS, Chart.js를 사용하며 낚시 기록을 브라우저 IndexedDB에 저장합니다.

## 사용 방법

1. `index.html`을 브라우저에서 열거나 GitHub Pages에 배포합니다.
2. 날짜, 어종, 무게, 길이, 장소를 입력하고 기록을 추가합니다.
3. 기록은 브라우저에 저장되며, 그래프와 통계가 자동으로 업데이트됩니다.

## 배포

1. GitHub 저장소를 생성합니다.
2. 이 프로젝트를 푸시합니다.
3. GitHub 저장소 설정에서 `Pages`를 활성화하고 `main` 브랜치 `root`를 선택합니다.
4. 잠시 후 `https://<사용자명>.github.io/<저장소명>/`에서 앱을 확인할 수 있습니다.

## 기능

- IndexedDB에 낚시 기록 저장
- 기록 목록 보기 및 삭제
- 사진(EXIF GPS) 업로드로 날짜와 위치 자동 입력
- 선단 정보, 출조 정보, 환경 정보, 채비 정보, 조과 정보, 특이 사항 기록
- 물때(1물~13물) API 조회 기능
- 시즌별 포인트 비교, 기상/루어 패턴 분석, 장비 효율성 평가 요약
- 전체 무게 및 마릿수 차트 표시
- 통계 카드: 총 기록, 총 무게, 평균 길이, 평균 마릿수, 추천 포인트, 최근 기록

## 설정

- `scripts/app.js` 내부 `TIDE_API_KEY` 변수를 `WorldTides` API 키로 설정하면 물때 조회 기능이 활성화됩니다.
